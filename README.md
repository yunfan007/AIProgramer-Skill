AI 程序员 Skill 规范集
本仓库收录了一系列面向 AI 编程助手（如 Cursor、GitHub Copilot、通义灵码等）的 Skill 规范文档，旨在将工程化、标准化、安全性的最佳实践固化到 AI 的协作行为中，使 AI 输出符合企业级研发要求。

这些规范不仅约束代码风格，更覆盖交互流程、技术选型、安全架构、部署运维等全生命周期，帮助团队在 AI 辅助开发中保持质量一致性。

📦 仓库内容
文件	适用场景
Programer Skill.md	通用程序员 Skill —— 涵盖交互准则、技术栈决策矩阵、数据库与安全规范、开发流程、代码与文档质量标准、部署适配要求以及可持续工程实践。
（更多 Skill 待补充）	后续将按 领域 或 语言 拆分细化，例如：Python Skill、Web Frontend Skill、Rust Skill 等，以适配不同技术栈的专项要求。
每个 Skill 文件均为独立可用的系统提示（System Prompt），可直接加载至兼容的 AI 编程环境中。

🚀 如何使用
方式一：在 Cursor / Windsurf 中导入
将所需的 Skill 文件内容复制到项目的 .cursorrules 或 rules.md 中；

或在 AI 会话开始时，将文件内容作为 系统指令 粘贴。

方式二：通过 @ 引用（支持自定义上下文）
在支持文件引用的 AI 工具中，直接输入 @Programer Skill.md 即可让 AI 遵循该规范。

方式三：作为团队标准模板
将本仓库克隆至团队内部，作为所有 AI 辅助开发项目的 基线规范，统一约定技术选型、变更流程和文档输出标准。

🧠 规范核心亮点
意图抑制机制：禁止 AI 猜测业务逻辑，缺失信息时必须主动提问，确保需求对齐。

技术栈决策矩阵：根据应用场景自动匹配最佳技术组合，避免主观偏好。

安全内建：强制使用 Argon2id/bcrypt 存储密码，参数化查询防注入，并规定中间件解耦策略。

流程闭环：从需求澄清到集成测试、变更管理，形成可追溯的工程流水线。

文档即代码：所有文档采用 Markdown，与代码版本同步，杜绝信息滞后。

可持续工程：推荐 CI/CD、依赖安全扫描、可观测性埋点，支撑长期演进。

📄 文档编写标准
本仓库所有 Skill 文档遵循内部《技术文档编写标准》：

使用规范 Markdown 格式，结构清晰（表格、列表、代码块）；

术语客观、精准，无营销化或 AI 式泛化表达；

更新记录与版本号同步维护。

🤝 贡献指南
欢迎提交 Issue 或 Pull Request 来完善现有 Skill 或新增领域规范。

新增 Skill 请遵循既有结构（背景 → 核心规范 → 约束条件 → 输出要求）；

所有规范需附带 示例 或 反例 以增强可操作性；

提交前确保 Markdown 格式正确，并更新根目录 README.md 中的文件列表。
